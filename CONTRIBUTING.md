# Contributing

This repo is curated, not crowdsourced. The bar is **"skill we use in production"**, and someone else's production is not ours to vouch for.

## What's welcome

- **Bug reports**: open an issue describing what you saw, what you expected, and a minimal reproduction.
- **Behavior reports from real use**: if a skill's instructions led an agent astray, that's a bug worth a report.
- **Suggested clarifications**: if a sentence in a SKILL.md is unclear or self-contradicting, open an issue with the specific quote.
- **Discussions**: broader questions about the methodology, comparisons, or use-case fit.

## What's generally not accepted

- **Pull requests for new skills.** The bar is too narrow for crowdsourced contributions. If you have a skill you think should be here, open an issue first; we'll tell you whether it's worth a PR.
- **Pull requests that broaden a skill's scope.** Skills here are deliberately small. Expansion proposals usually fail the curation test.
- **Mechanical edits** (whitespace, lint sweeps, mass-renaming) without prior issue. Drive-by churn is closed without review.

## What works

If a skill in here helps you and you want to upstream a fix or clarification:

1. Open an issue first. Quote the specific line(s).
2. Wait for a reply confirming whether a PR is wanted.
3. Only then send the PR.

This filter is the contribution policy. It is not personal.

## Reporting a security issue

See [`SECURITY.md`](SECURITY.md). Please report security issues privately rather than opening a public issue.
