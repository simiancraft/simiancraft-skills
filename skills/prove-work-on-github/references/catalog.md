## Fake proof (to recognize)

The negative space of the axiom; "pics or it didn't happen" failure modes. Initial list, to expand:

- **The confabulated URL.** A PR or run link that was never observed, asserted from memory.
- **Localhost dressed as CI.** A screenshot of a local run presented as the pipeline's result.
- **"I ran the command."** Exit code 0 reported as "the remote advanced"; the push was never confirmed.
- **The green checkmark that proves nothing.** A workflow ran; that is not "the feature works."
- **Stale reuse.** An artifact from an earlier commit presented for code that has since changed.
- **The moving referent.** Proof pinned to a branch name or `blob/main/...` instead of a SHA.
- **The leaky receipt.** Real proof that also exposes a token or credential; a liability, not an asset.
