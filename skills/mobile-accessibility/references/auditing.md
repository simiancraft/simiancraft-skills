# Accessibility auditing lens

Reference for **mobile-accessibility**. The driving skills read the tree for a **handle**;
auditing reads the same tree for **correctness**. This file is a thin seam: the minimum bar
and how it maps to the iOS fields. Deeper auditing (contrast, target size, full WCAG
conformance, automated audit tooling) belongs to the future general **accessibility** skill,
which expands this lens; do not duplicate that scope here.

## The minimum bar: name, role, value

The recognized lens is WCAG 2.1 Success Criterion **4.1.2 Name, Role, Value (Level A)**:

> *"For all user interface components (including but not limited to: form elements, links and
> components generated by scripts), the name and role can be programmatically determined;
> states, properties, and values that can be set by the user can be programmatically set; and
> notification of changes to these items is available to user agents, including assistive
> technologies."*

WCAG is written for the web; the **name / role / value** triad is the same lens an auditor
applies to a native mobile tree, and it maps directly onto the iOS fields this skill already
documents:

| WCAG 4.1.2 | iOS field | React Native prop |
|---|---|---|
| Name | `accessibilityLabel` | `accessibilityLabel` |
| Role | `accessibilityTraits` | `accessibilityRole` |
| State / Value | `accessibilityTraits` / `accessibilityValue` | `accessibilityState` / `accessibilityValue` |

## The checklist

Read a `describe-ui` dump (or inspect the source props) and confirm:

- Every interactive element **is** an accessibility element (`isAccessibilityElement` /
  `accessible` true) and has a **non-empty name** (`accessibilityLabel`).
- The name names the thing, **not its type**: "Save," not "Save button" (Apple's rule, see
  `references/ios-native.md`).
- The **role** matches behavior: a tappable element reads as a button, a link as a link.
- The **state** reflects reality: `disabled`, `selected`, and `checked` are set and update.
- A **value** is present when the label does not carry it (a slider's level, a field's text).
- The **focus order** is sane: elements are reachable in a sensible sequence.
